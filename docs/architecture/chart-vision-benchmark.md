## 结果解释

结构识别已经稳定：10 张图的图表类型、系列和类别/年份全部识别正确；有时间轴的 10 个系列趋势全部识别正确。名义类别图不计为升降趋势。数值结果不能简单理解为 OCR 准确率：折线图没有打印数值，模型只能从坐标估读；因此 90.5% 反映的是“在预设容差内的可用读数”，不是官方评分准确率。

主要剩余问题集中在折线图坐标估读；本基准中的堆叠柱状图因分段标签清晰，16/16 个数值均正确读出。系统已经将无标签读数标为 `estimated` 并写入不确定项；这些估读值不能直接作为 Task Achievement 的确定性扣分依据。正式评分前仍应在界面展示 `chart_understanding`，允许用户确认或修改图例、类别和数值。

完整逐张结果保存在 `tests/fixtures/chart_benchmark/results/summary.json`，每张图的标准答案和来源在同目录的 JSON 文件中。
